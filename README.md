# LMS Tools

A collection of standalone HTML tools and enhancements designed to support teaching and learning in LMS environments.

These tools are primarily intended for use with LMS **Text and Media Area** components and similar HTML-enabled content areas. They are designed to be simple, lightweight, and easy to copy, customise, and embed.

## 🧰 Tools

### Weekly Schedule Builder

**File:** [`WeeklyScheduleBuilder.html`](https://github.com/TonyLatrobe/lms/blob/main/WeeklyScheduleBuilder.html)

A small browser-based tool for creating subject/module schedules.

Features include:

* Select the number of modules
* Set the start week
* Add an optional mid-semester break
* Paste a weekly schedule
* Automatically calculate weekly date ranges
* Generate an LMS-ready schedule
* Copy the generated HTML for use in an LMS

The default configuration supports **12 modules**.

---

### Tab Builder

**File:** [`tabBuilder`](https://github.com/TonyLatrobe/lms/blob/main/tabBuilder)

A browser-based tool for creating tabbed content without writing the tab interface manually.

Features include:

* Add as many tabs as required
* Give each tab a custom title
* Add text or HTML content
* Support HTML generated by tools such as **hilite.me**
* Compile the tabs into standalone HTML and JavaScript
* Copy the generated code to the clipboard
* No external libraries or dependencies

This is particularly useful for presenting related content in a compact LMS page.

## 💡 Using the Tools in an LMS

Most of the tools are designed to work without installing software or adding external dependencies.

A typical workflow is:

1. Open the required tool.
2. Configure or create the content.
3. Generate the HTML.
4. Copy the generated code.
5. In the LMS, open a **Text and Media Area** (or equivalent HTML-enabled component).
6. Open the **source code / HTML editor**.
7. Paste the generated code.
8. Save the component.

The generated content is intended to be self-contained so it can be embedded directly into an LMS page.

## 🧑‍💻 Design Philosophy

These tools aim to follow a few simple principles:

**Standalone**
Each tool should work as a single HTML page wherever possible.

**Lightweight**
Avoid unnecessary frameworks and dependencies.

**Copy and paste friendly**
Generated HTML should be straightforward to move into an LMS.

**Teacher friendly**
The tools should make common LMS content tasks easier without requiring extensive coding knowledge.

**Reusable**
Generated components should be usable independently of the builder that created them.
