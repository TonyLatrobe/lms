# LMS Tools

A collection of standalone HTML tools and enhancements designed to support teaching and learning in LMS environments.

These tools are primarily intended for use with LMS **Text and Media Area** components and similar HTML-enabled content areas. They are designed to be simple, lightweight, and easy to copy, customise, and embed.

## 🧰 Tools

### Weekly Schedule Builder

**File:** [`WeeklyScheduleBuilder.html`](https://github.com/TonyLatrobe/lms/blob/main/WeeklyScheduleBuilder.html)

A small browser-based tool for creating subject/module schedules.

Features include:

- Select the number of modules
- Set the start week
- Add an optional mid-semester break
- Paste a weekly schedule
- Automatically calculate weekly date ranges
- Generate an LMS-ready schedule
- Copy the generated HTML for use in an LMS

The default configuration supports **12 modules**.

### Tab Builder

**File:** [`tabBuilder`](https://github.com/TonyLatrobe/lms/blob/main/tabBuilder)

A browser-based tool for creating tabbed content without writing the tab interface manually.

Features include:

- Add as many tabs as required
- Give each tab a custom title
- Add text or HTML content
- Support HTML generated by tools such as **hilite.me**
- Compile the tabs into standalone HTML and JavaScript
- Copy the generated code to the clipboard
- No external libraries or dependencies

This is particularly useful for presenting related content in a compact LMS page.

### Phoneme Word Search Builder

**File:** [`phoneme_word_search_builder.html`](https://github.com/TonyLatrobe/lms/blob/main/phoneme_word_search_builder.html)

A browser-based builder for creating self-contained word-search activities using either ordinary letters or space-separated IPA phonemes. The builder includes a phoneme palette and supports entries such as `θ ɪ n = thin`, with the English word used as a learner hint.

Features include:

- Create word searches from plain English words or IPA phoneme sequences
- Use the built-in phoneme palette to enter IPA symbols
- Choose **Easy**, **Standard**, or **Challenging** difficulty
- Change grid size and allowed word directions according to difficulty
- Optionally show English-word hints
- Switch the generated activity between light and dark themes
- Regenerate the puzzle with a new layout
- Preview the exact learner activity before downloading
- Download the completed activity as a standalone HTML file
- Generate a builder-only answer key that can be viewed or printed
- Use mouse, touch, or keyboard controls to find words
- Give learners a press-and-hold **Hint** button that temporarily reveals an unfound word

The difficulty settings use an **8 × 8** grid for Easy, **10 × 10** for Standard, and **12 × 12** for Challenging, with progressively more word directions available.

The downloaded activity is self-contained and does not include the teacher answer key.

### Phoneme Wordle Builder

**File:** [`phoneme_wordle_builder.html`](https://github.com/TonyLatrobe/lms/blob/main/phoneme_wordle_builder.html)

A browser-based builder for creating self-contained Wordle-style activities in which learners identify a target word using letters or IPA phonemes. Teachers can provide their own word list, select the target word, and configure the activity before downloading it as a standalone HTML file.

Features include:

- Create Wordle-style activities using plain English words or IPA phoneme sequences
- Enter phonemes using a built-in IPA palette
- Select any word in the supplied list as the target
- Choose **Easy**, **Standard**, or **Challenging** difficulty
- Give learners 8 attempts on Easy, 6 on Standard, or 4 on Challenging
- Optionally show English-word and spelling hints
- Use a fixed phoneme keyboard so the layout remains familiar between activities
- Automatically add extra keys when custom words contain units not on the standard phoneme keyboard
- Switch between light and dark themes
- Preview the exact learner activity before downloading
- Download the completed activity as a standalone HTML file
- Provide Wordle-style feedback for phonemes in the correct position, in another position, or absent from the target
- Give learners a press-and-hold **Hint** button that reveals one unresolved letter or phoneme
- Restart the activity without reloading the builder

The phoneme keyboard uses a consistent chart layout, while custom letters or phonemes that are not part of that chart are added beneath it so custom words remain playable.

Difficulty controls the number of guesses rather than the word itself: **Easy** provides 8 attempts, **Standard** 6, and **Challenging** 4.

## 💡 Using the Tools in an LMS

Most of the tools are designed to work without installing software or adding external dependencies.

A typical workflow is:

1. Open the required tool.
2. Configure or create the content.
3. Generate the HTML.
4. Copy the generated code.
5. In the LMS, open a **Text and Media Area** (or equivalent HTML-enabled component).
6. Open the **source code / HTML editor**.
7. Paste the generated code.
8. Save the component.

The generated content is intended to be self-contained so it can be embedded directly into an LMS page.

---

## 🧑‍💻 Design Philosophy

These tools aim to follow a few simple principles:

**Standalone** Each tool should work as a single HTML page wherever possible.

**Lightweight** Avoid unnecessary frameworks and dependencies.

**Copy and paste friendly** Generated HTML should be straightforward to move into an LMS.

**Teacher friendly** The tools should make common LMS content tasks easier without requiring extensive coding knowledge.

**Reusable** Generated components should be usable independently of the builder that created them.
