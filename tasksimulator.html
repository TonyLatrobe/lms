Task Manager Simulator

Use your domain knowledge to build a Task Management Simulation where your students race the clock to complete work tasks, side-quests and MCQ/Short-Answer questions - before their timer runs out.

Instructions

Set the Timer (in minutes) at the top of the builder.

Click "+ New" to create an activity.

Give the activity a Name and a Description.

Choose a Type:

   Personal Activity - a "time waster" task (e.g. "Walk the dog") that deducts time when completed.

   Multiple Choice Question - add answer choices and tick the one correct answer.

   Short Answer - type the expected correct answer.

Choose a Consequence (Jailed / Divorced / Fined) and write a custom Consequence Message - this is shown to the student if they run out of time or get the question wrong too many times.

Set the Timeout (seconds) - how long the student has to complete this activity once it appears before the consequence triggers.

Click Save Activity.

Repeat to add more activities - drag and drop them in the Activities list on the right to reorder.

Click Generate, then Copy to Clipboard.

Go to your LMS page you want to add this.

Add a Text Area or use an existing text area.

Click Edit then click "</>"

Select all (control-A) and paste (control-V)

Turn Editing off

You and your students will be able to play the Task Manager Simulator.
